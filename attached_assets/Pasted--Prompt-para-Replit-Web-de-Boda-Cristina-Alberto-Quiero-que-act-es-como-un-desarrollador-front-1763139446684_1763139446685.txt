# Prompt para Replit — Web de Boda Cristina & Alberto

Quiero que actúes como un desarrollador front-end experto trabajando en Replit.

TU MISIÓN  
Crear y mantener una página web completa para la boda de **Cristina & Alberto** con un estilo elegante, moderno y muy visual, inspirado en la experiencia de usuario de esta web:  
https://segux.github.io/biyj/?inv=b  
(No copies código, solo la UX: navegación por secciones, scroll suave, estilo limpio.)

---

## 🎯 Objetivo de la web
1. Presentar la boda y la información del evento  
2. Facilitar la confirmación de asistencia mediante un **formulario con Webhook**  
3. Mostrar detalles útiles: ubicación, cronograma, dress code  
4. Mostrar número de cuenta para regalos

## 📌 Estructura obligatoria de la web (One Page)
Debe contener las siguientes secciones, accesibles desde un menú fijo superior:

### 1️⃣ Inicio (`#inicio`)
- Nombre grande de la pareja
- Fecha y ciudad
- Frase tipo: “Nos casamos y queremos celebrarlo contigo”
- Botón → scroll a sección Confirmar

### 2️⃣ Detalles (`#detalles`)
- Horario básico del evento
- Dirección del monasterio
- Botón/link → abrir Google Maps
- Breve descripción/dress code

### 3️⃣ Confirmar asistencias (`#confirmar`)
Texto previo indicando fecha límite.

Formulario con **estos campos exactos**:

| Campo | Tipo | Obligatorio |
|-------|------|-------------|
| Nombre y apellidos | input text | ✔ |
| Email | input email | ✔ |
| ¿Llevas acompañante? (Sí/No) | select | ✔ |
| Nombre y apellidos acompañante (solo si respuesta = Sí) | input text | Condicional |
| Intolerancias o alergias | textarea | ✖ |
| ¿Vas a coger transporte de la boda? | select (Sí/No) | ✖ |
| ¿Te vas a quedar hospedado/a? | select (Sí/No) | ✖ |
| Política de privacidad | checkbox | ✔ |

📍 Importante  
- Validación en front  
- Mensajes de error amigables  
- Tras envío → mensaje de éxito sin recargar la página

📍 Webhook  
```js
const WEBHOOK_URL = "https://mi-webhook-de-ejemplo.com/rsvp";
```
